# Reseller Panel & Key Management Web App

A complete, production-grade key management and reseller panel web application built with modern HTML5, CSS3 (Dark Theme), and ES6+ JavaScript.

## Features Included
1. **Secure Authentication System**: Separate Admin and Reseller login with persistent session management (`localStorage`).
2. **Credit & Balance Enforcement**: Resellers cannot generate license keys without sufficient balance credits.
3. **Key Generation & Pricing Tiers**: Automated alphanumeric key generation mapped to pricing tiers (24 Hours, 30 Days, Lifetime).
4. **Admin Credit Control**: Admin can instantly top-up credits for any reseller account.
5. **App Upload & Download Hub**: Centralized repository for uploading software/APK links with instant download accessibility.
6. **Key Revocation & Management**: Track active keys, notes, and revoke licenses instantly.

## How to Test
1. Open `index.html` in your browser or IDE Live Preview.
2. Sign in as Admin (`admin@reseller.com` / `admin123`) or Register a new Reseller account.
3. As an Admin, top up reseller credits or upload new apps.
4. As a Reseller, check your balance credits, pick a tier, generate keys, and download apps.
